# سامانه CRM هلدینگ آرمان

سامانه مدیریت مشتریان، پروژه‌ها، رزرو، قرارداد و پیگیری اقساط. داده در MongoDB Atlas ذخیره می‌شود و ورود کاربران با نشست امن انجام می‌شود.

## اجرای محلی

1. Node.js 20 یا جدیدتر نصب باشد.
2. فایل `.env` را از روی `.env.example` بسازید و مقدارها را پر کنید.
3. در MongoDB Atlas، از بخش Network Access آی‌پی این رایانه یا سرور را مجاز کنید.
4. سپس:

```bash
npm install
npm start
```

سامانه روی `http://localhost:3000` بالا می‌آید. نام کاربری و رمز اولین مدیر از `ADMIN_USERNAME` و `ADMIN_PASSWORD` خوانده می‌شود و فقط وقتی هیچ کاربری وجود نداشته باشد ساخته می‌شود. بعد از ورود، رمز را از داخل سامانه عوض کنید.

اگر رمز مدیر را گم کردید، `ADMIN_PASSWORD` را در `.env` بگذارید و این دستور را بزنید:

```bash
npm run reset-admin
```

## داده چگونه ذخیره می‌شود

هر بخش مجموعه خودش را دارد: پروژه‌ها و واحدها، مشتریان، قراردادها و اقساط، رزروها و پرداخت‌ها، سرنخ‌ها، تنظیمات و کاربران. ذخیره هر تغییر داخل یک تراکنش انجام می‌شود. اگر دو نفر هم‌زمان ویرایش کنند، نسخه قدیمی‌تر رد می‌شود تا نوشته روی نوشته نرود. کد ملی مشتری و شماره پیگیری فیش تکراری پذیرفته نمی‌شود. متن قراردادهای ویرایش‌شده قبل از ذخیره از اسکریپت پاک می‌شود.

اگر قبلاً با فایل HTML قدیمی در همین مرورگر کار کرده باشید و پایگاه خالی باشد، سامانه پیشنهاد می‌دهد همان داده محلی به سرور منتقل شود.

## استقرار روی لیارا

1. در پنل لیارا یک برنامه **NodeJS** بسازید (پورت `3000`).
2. یک دیتابیس **MongoDB** در لیارا بسازید (یا از Atlas استفاده کنید) و connection string را بردارید.
3. در بخش متغیرهای محیطی برنامه این‌ها را بگذارید:

| متغیر | مقدار پیشنهادی |
| --- | --- |
| `NODE_ENV` | `production` |
| `PORT` | `3000` |
| `MONGODB_URI` | آدرس MongoDB لیارا/Atlas (با نام دیتابیس در مسیر) |
| `SESSION_SECRET` | رشته تصادفی حداقل ۱۶ کاراکتر |
| `COOKIE_SECURE` | `true` (چون لیارا HTTPS می‌دهد) |
| `ADMIN_USERNAME` | مثلاً `admin` |
| `ADMIN_PASSWORD` | رمز قوی مدیر اول |
| `ADMIN_NAME` | مثلاً `مدیر سیستم` |

4. از ریشه پروژه:

```bash
npm test
npm run smoke
liara deploy
```

فایل `liara.json` از قبل پورت و نسخه Node ۲۰ را تنظیم کرده است. بعد از بالا آمدن، با `/api/health` وضعیت را چک کنید و فوری رمز مدیر را از داخل سامانه عوض کنید.

## استقرار روی سرور

با Docker:

```bash
docker compose up -d --build
```

بدون Docker، پوشه پروژه را روی سرور بگذارید، `.env` را با `NODE_ENV=production` پر کنید، و اگر پشت HTTPS هستید `COOKIE_SECURE=true` بگذارید. سپس:

```bash
npm ci --omit=dev
npm start
```

نمونه سرویس systemd در `deploy/arman.service` و نمونه Nginx در `deploy/nginx.conf` است. بعد از راه افتادن Nginx، گواهی HTTPS را با ابزار خود سرور فعال کنید.

پشتیبان را مدیر از دکمه «پشتیبان» در نوار کناری می‌گیرد. این فایل شامل رمز کاربران نیست.

## نکته امنیتی

فایل `.env` را در گیت یا جای عمومی نگذارید. اگر رمز پایگاه داده جایی دیده شده، از MongoDB Atlas عوضش کنید و مقدار جدید را فقط در `.env` سرور بنویسید.
